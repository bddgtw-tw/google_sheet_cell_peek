# Privacy Policy

## Data handling

google_sheet_cell_peek processes Google Sheets cell content locally in the active browser tab only.

- No spreadsheet content is uploaded to a server.
- No analytics, advertising, tracking, or external API is used.
- The extension does not collect account credentials, browsing history, or personal identifiers.
- Local preferences such as enabled state and preview font size are stored with Chrome storage.

## Permissions

The `debugger` permission is used only to send click and edit events to the active Google Sheets tab because the Sheets grid is rendered with Canvas. The extension uses the permission for the user-facing cell preview and editing features.

The extension runs only on Google Sheets URLs matching `https://docs.google.com/spreadsheets/*`.

## Changes

This policy may be updated when the extension's data handling changes. The current version will be kept with the project source.
