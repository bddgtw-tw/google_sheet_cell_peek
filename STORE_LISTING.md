# Chrome Web Store listing draft

## Short description

Preview, copy, count, resize, and edit long Google Sheets cell content.

## Detailed description

Google Sheet Cell Peek helps you work with long cell content without expanding rows or columns.

Click a cell to view the complete content in a floating window. Copy it, edit it, save it back to the selected cell, adjust the preview text size, or see an estimated half-width character count.

The extension is designed as a focused personal productivity tool for Google Sheets. It has no ads, analytics, backend service, or external data upload.

## Known limitations

- Works on Google Sheets pages only.
- The `debugger` permission is required for reliable interaction with the Canvas-based Sheets grid.
- This is currently an experimental MVP.
