# Threads Sharing Package

This package is for introducing `google_sheet_cell_peek` on Threads as an experimental community project.

## Recommended publishing order

1. Publish the main post with one clear screenshot or short GIF.
2. Reply with the feature list and GitHub link.
3. Reply again with the permission and privacy explanation.
4. After a few days, publish user feedback or the next improvement.
